# 医疗科普创作工作室

把用户的健康科普方向推进为本次需要的产物：需求简报、候选选题、证据卡、文案分镜、视觉制作包，或有实际工具支持的候选图片与归档记录。沿用用户语言，默认使用中文。

## 运行边界

这是由当前智能体执行的独立 Skill。Coze 工作流是另一套运行在 Coze 的应用；安装本 Skill 不会安装、调用或更新这些工作流，也不会取得作者的模型、飞书资产和账号权限。本 Skill 的本地项目结构也不是 Coze 节点协议。

先识别本轮请求的范围和当前可用工具。文字策划可直接完成；医学事实需要可读取的资料或联网检索；实际图片需要图像生成工具；飞书写入需要使用者自己的连接和明确的保存请求。没有对应工具时交付已完成的内容与可执行制作包，并明确哪些步骤尚待执行。

## 从用户已有材料开始

- 读取当前任务已有需求、资料和产物，保留已确认信息。只问影响本轮工作的缺项，通常先确定科普方向、目标读者与本次用途；平台、比例和风格可在视觉制作前补齐。
- 用户只要一个模块，就在该模块范围内工作。已有选题与资料时可直接研究或编写；只收集需求时不扩展为生图和外部保存。
- 用户未限定终点时，按“需求 → 选题 → 研究 → 文案分镜 → 视觉 → 交付”推进。将需要用户决定的选题或内容边界说明清楚，不制造逐步回复“继续”的门槛。
- 需要跨轮次或文件交付时，在用户指定输出目录保存项目；未指定时使用工作区内独立目录。按[项目状态约定](references/project-state.md)保存 `project.json`，用 [assets/project.template.json](assets/project.template.json) 起步。可用 Python 3.10+ 时执行 [scripts/init_project.py](scripts/init_project.py)，它不会覆盖已有目录；没有 Python 时手工复制模板即可。

## 内容准备与创作

处理需求、选题、研究或文案时，读取[内容生产方法](references/content-pipeline.md)。

1. **需求：** 区分科普方向与具体痛点选题，整理读者、年龄、困扰、场景和制作偏好。原始需求不被候选标题覆盖。
2. **选题：** 提供适量、互相可区分的候选，解释适合读者与讲述角度。检索支持的观察与策划推测分别说明。用户明确选中后，本轮开始研究并交付研究结果；对候选的追问或无效序号不视为已选。
3. **研究：** 阅读与本题相关的权威资料，建立“主张—来源—适用范围”的证据卡。没有可读来源时提供待核实提纲，不编造引用、检索结果或确定性医学结论。证据有限时说明限制，得到用户同意后仅在可支持的范围内创作；技术读取失败不能当作证据不足放行。
4. **文案与分镜：** 根据已确认读者和内容范围写标题、正文与逐页计划。每页交代锁定文字、画面任务及对应证据。页面数量按需求安排，不把固定六页当作所有任务的标准。用户已明确授权完整制作且信息齐全时继续完成，不重复索要确认。

## 视觉与交付

需要视觉方案、实际出图或飞书归档时，读取[视觉制作与交付](references/visual-and-delivery.md)。

- 先统一风格、角色参考、配色、布局和锁定文字，再逐页制作。不同主题替换知识依据与场景，保留仍适用的视觉资产。
- 有图像工具且用户请求出图时，调用当前宿主支持的工具，记录真实输出。需要参考图时使用用户提供或有权使用的资产。只有提示词或页面计划时，称为“视觉制作包”。
- 图片生成、质量复核、外部保存各自记录状态。有至少一张真实候选图时报告已生成的张数；部分缺页或保存失败分别说明。检查中文文字、医学含义、人物一致性和页码关系，无法可靠检查的页面标为待复核。
- 用户要求保存飞书时，先读取目标表的实际字段与附件规则，再映射逐页内容；只用本人配置的连接。保留成功记录和失败页，重试前核对已写入结果，避免重复创建。没有写入能力时交付本地归档清单，不声称已保存飞书。

## 修改与续做

按[项目状态约定](references/project-state.md)处理失效范围：同方向换选题保留需求和推荐计数，更新研究及下游；换风格重做视觉，保留仍适用的文案。用户明确换方向时新建项目或保存旧版后重开。当前方向成功重推荐累计五轮后，要求补充具体偏好才再推荐；已有明确偏好时直接使用，不清零绕过门槛。

## 交付方式

向用户展示可直接阅读的内容、图片和文件位置；结构化状态放在文件中。完成有文件的项目后可运行 `python <本Skill目录>/scripts/validate_project.py <项目目录>` 检查结构、关联和本地文件。这个检查不验证医学真实性或图像质量，不据此宣称医学审核通过。

按用户所需终点交付：说明完成了哪些内容、候选图数量及复核情况，或需要补充的具体输入。只有真实工具返回才能支持“已生成图片”“已写入飞书”等结论。

需要将方法改用于课程、产品教程或培训图卡时，读取[独立模块与迁移示例](references/reuse-examples.md)，为新领域替换依据与需求字段。

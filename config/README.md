# 配置自己的Coze与飞书

本目录提供配置位置清单。`connections.example.json`和仓库根目录`.env.example`全部使用占位符，不包含作者的实际应用、工作流、空间或表格标识。

## 本地记录配置

按需复制为本地文件：

```powershell
Copy-Item config/connections.example.json config/local.json
Copy-Item .env.example .env
```

在本地文件里填写自己的值。`.gitignore`已排除`config/local.json`和`.env`。

这些模板用于记录配置位置，Coze不会自动读取此仓库的本地文件。真正执行时，需要在自己Coze空间的工作流、插件、知识库和飞书连接中配置相应信息。

## 配置清单

| 配置 | 填写在哪里 | 用途 |
|---|---|---|
| Coze空间和工作流标识 | 自己空间中的工作流调用节点 | 连接主对话、研究和图文子流程 |
| 飞书应用ID与密钥 | 应用认证及对应连接配置 | 访问自己的规则、素材和结果表 |
| 飞书多维表格标识 | 表格读取、上传或写入节点 | 定位自己的内容数据 |
| 飞书各表标识 | 平台规则、角色、风格、布局、结果等节点 | 区分不同业务数据 |
| 知识库 | 医学研究的检索节点 | 提供自己的内容依据 |

配置完成后，按[使用说明](../docs/使用说明.md)连接模块并试用。新增截图或导出材料前，检查画面和文件内容，确保实际凭证及私人链接没有进入仓库。
